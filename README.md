  <h1># Charity App</h1>

  <p>
    Charity App is a Flutter-based mobile application designed to connect individuals and organizations for charitable purposes. It enables easy donations, event participation, campaign management, and progress tracking, all in one platform.
  </p>

  <hr/>

  <h2>## <strong>Features Implemented So Far</strong></h2>

  <h3>### 1. Donation Management</h3>
  <ul>
    <li>Browse and contribute to various campaigns with ease.</li>
    <li>Track donation history and monitor ongoing campaigns.</li>
  </ul>

  <h3>### 2. Volunteer Opportunities</h3>
  <ul>
    <li>Find and sign up for local or global volunteer events.</li>
    <li>Get reminders and view past participation history.</li>
  </ul>

  <h3>### 3. Campaign Creation</h3>
  <ul>
    <li>Create and manage fundraising campaigns with multimedia support.</li>
    <li>Share campaigns with other users or on social platforms.</li>
  </ul>

  <h3>### 4. Impact Tracking</h3>
  <ul>
    <li>Visual dashboards to show real-time impact and progress.</li>
    <li>Notifications and campaign updates via push notifications.</li>
  </ul>

  <h3>### 5. User Dashboard</h3>
  <ul>
    <li>View donation records, event sign-ups, and saved campaigns.</li>
    <li>Manage account settings and preferences.</li>
  </ul>

  <hr/>

  <h2>## <strong>Tech Stack</strong></h2>
  <ul>
    <li><strong>Frontend:</strong> Flutter (Dart)</li>
    <li><strong>Backend:</strong> Firebase (Authentication, Firestore)</li>
    <li><strong>State Management:</strong> Provider</li>
    <li><strong>Animations:</strong> flutter_animate</li>
    <li><strong>API Handling:</strong> http package</li>
    <li><strong>Storage:</strong> SharedPreferences (for local state persistence)</li>
  </ul>

  <hr/>
